# Frontier Protocol 0.1.0-alpha.1

This is an alpha prerelease, not a stable release. Back up every world before
testing it. It is intended for modpack development and integration testing
against the following exact compatibility matrix:

- Minecraft `1.21.1`
- Java `21`
- NeoForge `21.1.235` or newer for Minecraft 1.21.1
- Create `6.0.11` or newer
- Create: The Factory Must Grow (TFMG) `1.2.0` or newer
- Fungal Infection: Spore exactly `2.2.0j`

The permanent tag-specific JAR URL is:

```text
https://github.com/upiscium/FrontierProtocol/releases/download/v0.1.0-alpha.1/frontier_protocol-0.1.0-alpha.1.jar
```

The release includes `frontier_protocol-0.1.0-alpha.1.jar`, its published
SHA-256 file, `release-manifest.json`, and `LICENSE`. Dependency JARs are not
bundled. BSD-3-Clause applies only to Frontier Protocol source code and original
assets; dependencies and retained third-party material remain under their own
licenses.

All [documented alpha boundaries](../alpha-release.md#alpha-boundaries) remain
in effect. This prerelease does not claim stable support or compatibility
outside the documented matrix.
