## Supported Scope

Frontier Protocol provides permanent initial-spawn suppression and three
stationary Create-powered Stabilizers: Tier 1, Tier 2, and Tier 3, covering 1x1,
3x3, and 5x5 chunks. All tiers use the common Stabilization Cell. Suppression is
dimension-local and overlap-safe, and ACTIVE Stabilizers perform bounded cleanup
of audited Spore foliage in loaded chunks without loading additional chunks.

Operational support includes Engineer's Goggles diagnostics, targeted range overlays,
binary Nixie status output, comparator Cell-buffer output, localized
Ponder scenes, and the five documented Create production recipes.

Supported limitations remain intentional. Containment does not stop hostile mobs,
combat, block breaking, or explosions. It does not restore terrain, remove nests
or infected Block Entities, handle moving contraptions, load chunks, or provide
a machine GUI. Spore integration remains pinned to the exact audited `2.2.0j`
build.
