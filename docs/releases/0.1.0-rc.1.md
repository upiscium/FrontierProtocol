# Frontier Protocol 0.1.0-rc.1

`0.1.0-rc.1` is a prerelease candidate for Frontier Protocol `0.1.0`. This
document prepares a future Release; the RC tag, JAR URL, and GitHub Release are
not available yet.

## Platform

- Minecraft `1.21.1`
- Java `21`
- NeoForge `21.1.235`
- Create artifact `6.0.11-295` / mod `6.0.11`
- Create: The Factory Must Grow `1.2.0`
- Fungal Infection: Spore exactly `2.2.0j`

## Supported Scope

The candidate supports permanent initial-spawn suppression, three stationary
Create-powered Stabilizer tiers, common Stabilization Cells, dimension-local
overlap-safe containment, bounded loaded-chunk foliage cleanup, diagnostics,
range visualization, comparator/Nixie output, localization, Ponder scenes, and
the five documented Create production recipes.

Supported limitations remain intentional: containment does not stop hostile
mobs, combat, block breaking, or explosions; it does not restore terrain,
remove nests or infected Block Entities, load chunks, handle moving
contraptions, or provide a machine GUI. Spore integration remains pinned to the
exact audited `2.2.0j` build.

## Upgrade and Evidence

Back up worlds before testing a prerelease. Worlds from `0.1.0-alpha.1` may be
opened directly by this candidate. The retained R19 startup matrix verifies
fresh-world restart persistence, dependency diagnostics, and config recovery.
The retained R20 migration matrix uses the exact published Alpha JAR and checks
two current-candidate starts, the 16/8 over-capacity Cell inventory, exact chest
items, vanilla seed, spawn and cleanup SavedData, and block/entity/POI regions.

Before Stable, the exact merged RC/final candidate still requires retained
minimum-120-minute `rc-log-volume-soak` evidence, final graphical and packwiz
checks, final candidate reruns, frozen Stable notes/changelog, and remaining
license/publication gates. A short PR soak validates only harness infrastructure.

The future immutable RC JAR URL will be:

`https://github.com/upiscium/FrontierProtocol/releases/download/v0.1.0-rc.1/frontier_protocol-0.1.0-rc.1.jar`

This URL is not available until a later separately authorized publication.
Stable compatibility guarantees begin only with final `0.1.0` publication.
