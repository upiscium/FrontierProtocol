# 0.1.0 Known Issues

No issue is currently accepted as a known limitation of stable `0.1.0`.

This does not mean the Stable release is ready. Incomplete gates in the
[Stable gate ledger](0.1.0-stable-gates.md) remain publication blockers. Any
issue accepted for Stable publication must be added here with its impact and
workaround before the known-issues gate is approved.

The [R19 startup matrix](../r19-stable-startup-matrix.md) resolves the current
development-version evidence gaps for initial-spawn persistence, required
dependency diagnostics, malformed config recreation, and range correction. The
[R20 migration fixture](../r20-alpha1-world-migration.md) resolves the matching
development-version Alpha upgrade, item-integrity, world-integrity, and second
restart evidence gaps. The retained RC soak and public Packwiz candidate smoke
are accepted, but they do not substitute for the remaining blockers:

- exact final-candidate automated reruns;
- English graphical smoke;
- Japanese graphical smoke;
- final changelog freeze;
- final release-notes freeze;
- final license and provenance verification;
- Stable candidate verification; and
- Stable publication.
