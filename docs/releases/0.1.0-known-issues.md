# 0.1.0 Known Issues

No issue is currently accepted as a known limitation of stable `0.1.0`.

This does not mean the stable release is ready. Areas marked `NOT VERIFIED` in
the [stable-readiness blocker audit](../stable-readiness-0.1.0.md#blocker-evidence-audit)
remain release blockers until retained evidence resolves them. Any issue accepted
for stable publication must be added here with its impact and workaround before
the known-issues gate is approved.

The [R19 startup matrix](../r19-stable-startup-matrix.md) resolves the current
development-version evidence gaps for initial-spawn persistence, required
dependency diagnostics, malformed config recreation, and range correction. It
does not resolve the `NOT VERIFIED` alpha-world migration, upgraded-world
restart, item-loss/world-corruption, final-candidate, or long-running soak
boundaries.
