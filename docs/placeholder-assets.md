# Placeholder Assets

| Asset | Current placeholder | Final requirement |
| --- | --- | --- |
| Tier 1 offline | Vanilla block textures | Custom block model/texture |
| Tier 1 active | Vanilla block textures | Active emissive variant |
| Tier 1 grace | Vanilla block textures | Grace-period variant |
| Compound | Blaze Powder | Custom item texture |
| Cell | Prismarine Crystals | Custom item texture |

These placeholders are for the internal alpha only. Registry IDs and recipes are independent of final art. Replacing models and textures does not require changing world data. All placeholders must be replaced before public distribution, but final asset quality is not an R6 completion condition.

R6 adds no custom PNG files. The Compound model references `minecraft:item/blaze_powder`, the Cell model references `minecraft:item/prismarine_crystals`, and the Tier 1 state models continue to reference vanilla iron and deepslate-family block textures.
